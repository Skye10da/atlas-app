Discover Page Redesign

Proposed redesign for the Atlas App discover/home screen — transforming it from a static mock-data page into the dynamic heart of the app ecosystem.

Key Changes

  • Real data everywhere — Streak, stats, activity chart, and quotes now pull from the Drift database instead of hardcoded values
  • Weekly Reading Goal card New — Progress ring with daily streak badge, replaces the flat activity chart as the motivational anchor
  • Trending Now (OPDS) New — Pulls popular books from legal public OPDS catalogs (Gutenberg, Standard Ebooks, Feedbooks, Open Library) with source filters, rank badges, and download counts
  • Personalized "For You" recommendations New — ML-free genre-matching based on reading history with match percentages
  • Curated genre collections Improved — 2-column grid with gradient cards, expanded to include Classics from OPDS
  • Compact source pills Improved — Grid layout replaces vertical cards, saving vertical space
  • Notification bell New — Entry point for update alerts and milestone nudges
  • Quick stats row Improved — Icon-rich cards with real data replace the plain text trio
  • Responsive layout New — Uses AppResponsiveLayout for tablet/desktop grid adaptation

Trending Now — OPDS Integration

  • Data source: Public OPDS catalogs (Open Publication Distribution System)
  • Catalogs: Gutenberg, Standard Ebooks, Feedbooks, Open Library
  • Caching: Trending feeds cached locally with 24h TTL, refreshed on pull-to-refresh
  • Ranking: Sorted by recent download/popularity from OPDS feed metadata
  • Offline: Falls back to cached trending list when offline
  • Filter pills: Filter by source catalog, "All" shows merged results
  • Quick add: Tap card → book details → import to library in one step

Architecture

  • TrendingService fetches all 6 plugins in parallel via Future.wait
  • TrendingSelectors in each selectors.json define CSS extraction rules
  • PluginCapability.trending added to capability enum
  • SelectorSet.applyTrending() extracts title, cover, author, genre, rating, popularity
  • TrendingSection widget: horizontal scroll + source filter pills + book cards
  • Wired into DiscoverDashboardData.trendingBooks map (sourceId → books)
  • Failed sources silently skipped via AppLogger.warning
  • Refreshed on pull-to-refresh in Discover screen

Architecture Additions

  • discover/domain/ — ReadingGoal, Recommendation, TrendingBook entities
  • discover/infrastructure/ — RecommendationEngine, ReadingGoalRepository, OpdsTrendingService
  • discover/application/ — DiscoverAggregator service (combines book stats + goals + recs + trending)
  • discover/presentation/providers/ — discoverDataProvider, recommendationProvider, weeklyGoalProvider, trendingProvider
  • New Drift tables: reading_goals, reading_sessions, trending_cache
  • OPDS feeds: https://www.gutenberg.org/ebooks/opds, https://standardebooks.org/opds, https://www.feedbooks.com/catalog.atom

Sections (top → bottom)

  • 1. Header — Greeting + streak pill + notification bell
  • 2. Continue Reading — Dark hero card with real progress + quote
  • 3. Quick Stats — 3-column icon cards (Books / Chapters / Time)
  • 4. Weekly Goal — Green progress ring + streak badge
  • 5. Activity Chart — Real weekly data from reading_sessions
  • 6. Trending Now — OPDS-sourced popular books with source filters
