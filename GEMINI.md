# Agent Guidelines & Constraints

## Git Operations
- **Do NOT touch Git unless explicitly requested**: Never run Git commands (git add, git commit, git push, git checkout, git branch, git stash, git reset, git status, etc.) or modify Git repository state, unless the user explicitly and specifically instructs you to do so in their prompt.
- When proposing or applying changes, only modify or create the necessary project files. Do not stage changes, create commits, switch branches, or alter Git state automatically.
